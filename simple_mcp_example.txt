what is the like minimal way to set up mcp with claude code
The minimal way to set up MCP with Claude Code is to add an MCP server using the basic command syntax1:

bash
claude mcp add <name> <command> [args...]
1

For example, to add a local server1:

bash
claude mcp add my-server -e API_KEY=123 -- /path/to/server arg1 arg2
1

After adding the server, you can verify it was configured correctly1:

bash
claude mcp list
1

You can also check the server status anytime using the /mcp command within Claude Code1.

For remote servers, the setup is even simpler since they require no local installation - just add the vendor's URL2:

bash
claude mcp add --transport sse sse-server https://example.com/sse-endpoint
1

The server will be available in local scope by default, meaning it's only accessible to you in the current project1.

and do we need to create like a file to make sure or does it appear in a specifc config somewhere or what?
No, you don't need to create a file manually. The configuration is automatically stored based on the scope you choose1:

Local scope (default): Stored in your project-specific user settings1

Project scope: Creates or updates a .mcp.json file at your project's root directory1. When you add a project-scoped server, Claude Code automatically creates this file with the configuration structure1:

bash
claude mcp add shared-server -s project /path/to/server
1

This creates a .mcp.json file that follows this format1:

json
{
  "mcpServers": {
    "shared-server": {
      "command": "/path/to/server",
      "args": [],
      "env": {}
    }
  }
}
1

User scope: Stored in your user configuration, available across all projects1

bash
claude mcp add my-user-server -s user /path/to/server
1

You can also create an MCP configuration file manually and load it using the --mcp-config flag2:

json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/path/to/allowed/files"
      ]
    }
  }
}
2

The configuration is automatically managed - you just need to add servers using the claude mcp add command and they'll be stored in the appropriate location based on your chosen scope1.
